# Portfolio Maintenance Skill

## Workflow
1. **Understand Layout:** Review `src/pages/index.tsx` for section ordering and featured projects.
2. **Add/Update Projects:** Place top priority projects (like Aether AI) at the top of the `Work` section. Ensure screenshot previews are updated in `src/images/`.
3. **Verify Build:** Always run `npm run build` to ensure static HTML generation and GraphQL schemas are error-free.
4. **Development Server:** Run `npm run dev` to preview live updates.
